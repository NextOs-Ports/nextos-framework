# V5 publication tooling review

[Português](V5-REVIEW-20260912.md)

This review fixes tools in the collection prepared for publication. It keeps the V5 runtime, NXExtract, interfaces, native examples and port snapshots frozen. V6 was not incorporated. The repository remains private.

## Implemented fixes

| Boundary | Observed failure | Fix |
| --- | --- | --- |
| Frozen selection | Accepted additional files and executable-bit changes | Requires the exact set, hashes and executable modes, without symlinks |
| V5 identity | Changing runtime and its hash in the manifest itself could pass | Also pins the V5 export manifest SHA-256 |
| Workspace | Force-added Git data in ignored directories could escape | Rejects tracked content in `work/`, `build/`, `inputs/`, caches and environment files |
| ELF inventory | ELF64 could appear as ARMv7 without a blocker | Checks class, machine, header version and size; flags requirements already rejected by V5 loader |
| Android set | Accepted duplicate bases/splits or conflicting known versions | Rejects duplicate identities and conflicting versions; preserves unknown fields |
| Limits | Applied 8 GiB per APK; decompressed manifest before checking 2 MiB | Sums all APKs and checks the manifest before reading |
| Recovery | Special characters changed the URL; provenance could be overwritten | Encodes the path, compares already pinned hashes and requires new files |

The new [V5 collection checks](../.github/workflows/collection.yml) workflow runs integrity, bilingual guides and tooling tests on push/PR. It uses only the collection and synthetic fixtures. [Full SDK training](../.github/workflows/onboarding.yml) remains manual. Neither workflow publishes commercial data or game artifacts.

## Evidence and limits

48 host tests passed: 17 scope/integrity, 13 Android compatibility, 12 inventory/catalog and 6 recovery tests. Negative cases include 32/64-bit ELF, split versions, altered manifest, additional file, permissions, symlinks and a mocked URL. Mocked recovery does not prove external server availability.

The preserved manifest SHA-256 is `c038cd9bb1e9bfedc0f24a8b51639fccf5a464a3dfd474b950463315bcb59662`; its origin remains `framework-v5` / `657fb65a23b5c3b20040e76307b27e6470b1d17c`. The verifier checks the 1,285 export files and port selections. It examines the current tree and Git index paths without certifying the entire history or shim coverage.

SDK, ARM examples, NXExtract and games were not rebuilt or rerun. Earlier evidence retains its own bytes and limits in [ONBOARDING-UPDATE.en.md](ONBOARDING-UPDATE.en.md). No physical test, ZIP, release, migration or visibility change occurred.
