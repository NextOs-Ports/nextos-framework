# Sonic 4 Episode II compatibility package

This archive contains the NextOS compatibility loader, launcher, package
metadata, setup helpers, preview images and redistributable runtime libraries.
It does not contain `libfox.so`, `data.obb`, APK files or other Sonic The
Hedgehog 4: Episode II runtime game data. The user must provide a legally
obtained Android v3.0.0-109 ARM64 copy.

Sonic The Hedgehog 4: Episode II is property of SEGA and its respective
rightsholders. Detailed source, dependency and game-data notices are in
`licenses/`.
