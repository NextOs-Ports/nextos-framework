NAMELESS CAT — NextOS Ports (BYO data / dados por sua conta)
============================================================

PT-BR
-----
Este pacote NAO contem nenhum dado do jogo. Nenhum APK, nenhum asset e
nenhuma biblioteca da Kotoba Games acompanha o download — apenas o codigo
aberto do port.

Para jogar, copie para ESTA pasta o pacote Android do Nameless Cat 1.15.2
que voce possui legalmente (base + split arm64-v8a, ou o pacote completo
.apkm/.apks/.xapk/.zip). O instalador reconhece o jogo pelo CONTEUDO, entao
o nome dos arquivos nao importa.

Na primeira abertura o instalador extrai, valida e publica os dados; nas
aberturas seguintes ele so confere o marcador e vai direto para o jogo.
Os seus arquivos NUNCA sao apagados.

Se aparecer "nenhum conjunto de entrada casa com esta receita", o pacote
provavelmente e de OUTRA versao do jogo (ou de outro jogo). Os detalhes
ficam em nxextract.log, dentro da pasta namelesscat.

EN
--
This package contains NO game data: no APK, no assets and no Kotoba Games
libraries ship with the download — only the port's own source code.

To play, copy the Android package of Nameless Cat 1.15.2 you legally own
(base + arm64-v8a split, or the whole .apkm/.apks/.xapk/.zip bundle) into
THIS folder. The installer identifies the game by CONTENT, so file names do
not matter.

The first launch extracts, validates and publishes the data; later launches
only check the marker. Your files are never deleted.

If you see "no input set matches this recipe", the package is most likely a
different version of the game (or a different game). Details land in
nxextract.log inside the namelesscat directory.
