## Noncommercial restriction under review

The maintainer wants to restrict commercial exploitation and preserve credits. **This private preparation does not change existing licenses.** GPL permits sales and does not accept an added blanket commercial prohibition. Creating this repository also does not cancel existing MIT or other permissions.

One option for new guide text is CC BY-NC-SA 4.0, with separately licensed code snippets. This remains a decision for editorial/legal review before publication. It will not be overlaid on GPL-derived code. Independently owned software may use another license after compatibility review. A noncommercial restriction is not open source under the OSI definition.

## Cases requiring specific reading

- Freedom Planet 2: GitHub detects MIT, but NOTICE identifies loader/hooks/GLES as GPL-3.0-only and helpers as MIT. Automatic detection does not replace that scope.
- Forager: GPL-2.0-only. Including it as a separate reference does not authorize mixing its code into GPLv3 components.
- Beach Buggy and FF4: GPLv3 licenses are in the game subdirectories.
- PartyBoard/Pikmin: MIT is limited to NextOS contributions; this selection does not include the entire reconstructed game-code tree.

Existing upstream notices govern their respective content. Privacy omissions and legal-notice completeness need review before making the collection public. NextOS attribution neither replaces third-party credits nor establishes ownership of the original game.
