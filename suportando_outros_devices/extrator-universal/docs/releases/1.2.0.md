# NXExtract 1.2.0

Feature release adding a reusable firmware-first runtime boundary and
reconciling the embedded source diagnostics with 1.1.2 behavior.

## Changes

- restores the expected v1.1.2 diagnostic when a source pattern matches files
  but all of them fail size, hash, CRC or ELF validation;
- retains the 1.1.2 fast-marker and transactional `--force-source` paths;
- adds `nxextract-runtime-env.sh`, used automatically by
  `run-extractor.sh`, to put firmware-native library directories first and
  exclude `LD_LIBRARY_PATH` entries inside the game directory;
- preserves a valid inherited SDL backend and leaves SDL autodetection intact;
  the helper never forces `SDL_VIDEODRIVER`;
- adds the explicit `NXEXTRACT_SDL_AUTODETECT=1` recovery route for a launcher
  that has already proved inherited video/audio overrides invalid; it only
  clears those overrides in the extractor child and never chooses a backend;
- adds direct and launcher-level regression coverage for the runtime boundary.

The Python core still supports Python 3.7 or newer. The bundled AArch64 UI is
unchanged and requires only GLIBC 2.17. No proprietary game data is included.
