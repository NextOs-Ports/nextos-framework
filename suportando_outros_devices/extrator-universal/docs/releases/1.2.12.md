# NXExtract 1.2.12

NXExtract 1.2.12 adds ONE optional recipe member and changes nothing else:
recipes without it produce byte-identical behaviour, markers and seals.

## `mutable` paths (P12)

Field case: a game that stores its save INSIDE the sealed payload
(`assets/mySave.sol` on Tightrope Theatre) breaks the payload metadata seal on
every play session, so every launch re-validates the installation and shows
the setup UI instead of booting straight into the game.

A recipe may now declare `"mutable": ["assets/mySave.sol", ...]` — up to 32
relative paths (files or directories, no `{abi}`), each of which must live
under a commit path. Objects matching a mutable path are excluded from the
payload metadata seal at write AND verify time, so guest-written saves can no
longer invalidate the marker. Everything else in the seal — every other file's
name, size and mtime — keeps exactly the 1.2.11 semantics, and the mutable
list is bound to the recipe digest already recorded in the marker.
