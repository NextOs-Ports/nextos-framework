# NXExtract 1.2.13

NXExtract 1.2.13 fixes the terminal receipt for an already successful visible
setup. The renderer proof is now retained as historical run evidence while the
live UI process, private `ui.ready`/`ui.stop` controls and runtime directory are
cleaned up normally.

Previously, cleanup reset the live `ready` and `renderer` fields before
`nxextract-result.json` was assembled. The compact log correctly recorded a
graphical `sdl` or `fbdev` renderer, but the terminal JSON incorrectly reported
`ui.mode=disabled` with a null renderer. The extraction itself was unaffected.

The fix separates the immutable terminal receipt from live process state:

- an attested SDL setup publishes `visible` + `sdl`;
- an attested direct-framebuffer setup publishes `visible` + `fbdev`;
- a headless fallback retains its reason;
- an absent/disabled UI remains `disabled`.

The UI source, all four GLIBC 2.17 release binaries, 640x480 and 1280x720 pixel
goldens, timing, layout, colors, renderer order and transaction flow are
unchanged.
