# NXExtract 1.1.2

Maintenance release improving repeat-launch performance, transactional source
upgrades and diagnostics when a provided package is a different build of the
expected game.

## Changes

- committed trees use anchor `required_paths` on the normal marker path instead
  of a full SD-card tree walk; install, update, verification and adoption keep
  full validation;
- `install --force-source` performs an explicit transactional reinstall while
  preserving the live payload until the new stage validates and publishes;
- when every file that matches a payload's source pattern is rejected by
  validation (size, sha256, crc32 or ELF machine), the plan error now reports
  how many candidates matched, names one of them and states that the input is
  probably a different build, instead of the misleading plain
  `required payload ... was not found`;
- source selection and full install/update validation remain strict;
- a synthetic regression test covers the new diagnostic.

The AArch64 UI is unchanged from 1.1.0 and still requires only GLIBC 2.17.
No APK, OBB, game library, game asset or other proprietary data is included.
