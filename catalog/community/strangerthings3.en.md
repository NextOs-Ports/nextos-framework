## Profile and lessons

The Unity study records gameplay, audio and persistence for build 6000.2.6f2. The key boundary was StreamingAssets: the supplied path had to represent a real container with the complete asset tree. Providing only bundles left the flow incomplete. Rewired required one action per button to avoid simultaneous confirmation and cancellation.

Historical limits include a submenu font issue and forced exit. The exact source bound to the artifact must still be recovered before copying it as a final reference. This entry does not import other franchise titles or private files.
